## Intent

Make concrete the group isolation invariant: groups are independent financial contexts, and no operation may reference entities belonging to a different group.

## Boundaries

This behaviour covers scope validation at the domain level. Snapshot import (UC-013) creates a new group from exported data and does not cross-reference existing groups. Multi-group support (FR-012) allows switching between groups but never mixing their data.
