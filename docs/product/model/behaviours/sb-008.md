## Intent

Make concrete the single-currency constraint: each group is a closed financial context in one currency, and the product never converts between currencies.

## Boundaries

This behaviour is a direct consequence of CON-002 (no cross-currency conversion). The currency is set at group creation (UC-001) and cannot be changed after expenses are recorded. Users who track expenses in multiple currencies must create separate groups.
