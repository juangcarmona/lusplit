when: the split is evaluated and a remainder of minor units exists after integer division
then:
  - Leftover minor units are distributed one-by-one to participants
  - Participants are ordered by descending remainder, then by ascending participant ID using ordinal comparison
  - The same inputs always produce the same output across platforms

## Intent

Make concrete the deterministic rounding rule that guarantees reproducible split results across devices and platforms, eliminating ambiguity in penny-precision division.

## Boundaries

This behaviour covers the remainder distribution algorithm only. Fixed-amount splits (where each share is explicitly specified) do not produce remainders and are not affected. The ordinal string comparison for participant ID tiebreaking is an implementation detail that this behaviour makes observable.
