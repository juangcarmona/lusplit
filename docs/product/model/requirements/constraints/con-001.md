## Constraint

The product does not require user accounts, authentication, or sign-up. All data is local and private.

## Rationale

The product is designed for personal, offline-first use among trusted friends and family. Accounts would add friction without adding value for the target audience.

## Consequences

No cloud sync, no multi-device data sharing via accounts, no user identity across sessions. Data portability relies on snapshot export/import.
