## Goal

See each participant's net balance (how much they owe or are owed).

## Trigger

User views the balances tab in a group.

## Preconditions

A group exists with at least one expense.

## Main Flow

1. System calculates each participant's net balance.
2. System displays positive (owed) and negative (owes) amounts.

## Alternative Flows

- User switches to household-aggregated view when dependents exist.

## Failure Conditions

- No expenses recorded in the group (all balances are zero).

## Postconditions

None (read-only query).
